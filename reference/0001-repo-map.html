The three mission-critical numbers (from doc/inference_deployment_qa.md)

  • 155 trillion tokens/day served by one cluster.
  • US$38 per GPU-hour revenue at valley pricing — the disclosure that made people do math.
  • 72+ hours of KV-cache retention (chatbot TTL ≈ 7 d, agent ≈ 3 d) on ~100 PiB of 3FS storage.

What is deliberately NOT in this release (README:38-42)

  • An HTTP/API serving entrypoint. The only HTTP server is an internal profiling dashboard (engine/profile_server.py).
  • The production KV cache system: in-flight KV machinery lives in worker/cache_engine.py, but the persistent 3FS-backed store is external.
  • VE/Prefill/Decode disaggregation glue ("most required engine functionality is already implemented") and cross-replica DP load balancing.
  • DSML token-protocol handling — lives in the separate deepseek-recipe repo.

Key top-level files worth knowing

  • environ.py — every feature env var in one place (grep DEEPINFER_) — start here when a lesson names a knob.
  • sequence.py — per-sequence + GPU-resident zos bookkeeping (sampled tokens, MTP predicts, confidence rates).
  • sampling_params.py, shared_memory.py, model_config_loader.py, config.py (incl. SchedulerConfig).
